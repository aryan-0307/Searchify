PRIVACY POLICY

Effective Date: November 2026 • Version 1.0

TL;DR: Searchify is 100% client-side. We do not track you, do not use tracking cookies, and your algorithm data never leaves your browser.

1. Core Architecture & Client-Side Operation

Searchify (https://searchify.aryandixit.space) is an interactive, browser-based Data Structures and Algorithms playground designed and built by Aryan Dixit.

All sorting visualizers (Bubble, Selection, Insertion, Merge, Quick, Heap, Shell, Counting, Radix, Bucket), searching visualizers (Linear, Binary), and the Multi-Algorithm Showcase execute entirely inside your local web browser engine via Vanilla JavaScript. No array values, search keys, sorting steps, or benchmark results are ever transmitted to or stored on any server.

2. Information We Do NOT Collect

We respect your privacy by practicing absolute data minimization. Specifically:

  • No User Accounts: You do not need to register, sign in, or provide any email address or password to use Searchify.
  • No Analytics or Tracking Cookies: Searchify does not use Google Analytics, Meta Pixel, tracking beacons, or third-party advertising cookies.
  • No Personal Identifiers: We do not log names, IP addresses tied to user profiles, physical locations, or payment details.

3. Local Browser Storage

Searchify may utilize your browser’s standard localStorage or session memory solely to save your local UI preferences across refreshes (such as sound toggle state, audio volume, or preferred algorithm speed). This data resides exclusively on your device and can be cleared at any time through your browser settings.

4. Third-Party CDNs & Asset Delivery

To deliver high-performance typography and styling, Searchify requests font files from external content delivery networks (CDNs):

  • Google Fonts: Provides the Bricolage Grotesque and Inter font families. When your browser fetches font files, standard HTTP request headers (including IP address and user-agent) are handled by Google's font delivery servers in accordance with Google's Privacy Policy.
  • OnlineWebFonts: Delivers the Aalto Display font file.

5. Web Hosting & Infrastructure Server Logs

Searchify is hosted statically on modern edge networks (such as Vercel / GitHub Pages). Like all web servers on the internet, the hosting infrastructure may record standard, temporary HTTP connection logs (such as requesting IP address, requested path, timestamp, and user agent) for server diagnostics, DDoS defense, and infrastructure security.

6. Open Source Verification

Searchify is completely open source under the MIT License. You can inspect the entire codebase, all JavaScript algorithms, CSS styles, and deployment files directly in our public GitHub repository at github.com/aryan-0307/Searchify.
